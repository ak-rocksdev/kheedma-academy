# UX Psychology — Designing Apps People Can't Stop Using

> Psychological principles that make digital products habit-forming, engaging, and trust-building.

## 1. Core Principles

### Smart Defaults
- Pre-select the most beneficial option for the user, reducing cognitive load.
- Users stick with defaults due to **status quo bias**.
- Guide behavior gently rather than forcing choices.

### Sense of Progress
- Visual progress indicators (streaks, progress bars, checkmarks) trigger the **goal gradient effect** — people work harder as they near a goal.
- Break large tasks into small visible steps.
- Micro-rewards at each step reinforce engagement.

### Reciprocity
- Give value first (free trial, useful content, insight) — users feel obliged to give back.
- One of Cialdini's key principles of persuasion.
- Even small gestures trigger a sense of indebtedness.

## 2. Trust & Motivation

### Building Trust
- Be transparent about data use.
- Consistency in design builds reliability.
- Social proof (reviews, user counts) lowers perceived risk.
- Avoid dark patterns — deception destroys trust long-term.

### Motivation Design
- **Intrinsic**: Autonomy, competence, relatedness (Self-Determination Theory).
- **Extrinsic**: Badges, leaderboards — use sparingly.
- Match challenges to user skill level for competence.

## 3. Decision Fatigue & Framing

### Decision Fatigue
- More choices = lower decision quality over time.
- Use **progressive disclosure** — essential options first, advanced later.
- Smart defaults reduce active decisions.

### Framing Effects
- **Loss aversion**: People avoid loss more than they seek gain. Frame as "Don't miss out" over "Get this benefit."
- Positive framing for low risk; loss framing for high stakes.

## 4. Key Concepts Reference

| Concept | Description | UX Application |
|---|---|---|
| Status Quo Bias | People prefer things to stay the same | Smart defaults |
| Goal Gradient Effect | Effort accelerates near a goal | Show progress toward completion |
| Loss Aversion | Losses feel 2x stronger than gains | Frame as preventing loss |
| Reciprocity | People return favors | Offer value upfront |
| Social Proof | People follow others | User counts, reviews |
| Progressive Disclosure | Reveal gradually | Basic first, advanced on demand |
| Self-Determination Theory | Need autonomy, competence, relatedness | Control, challenge, connection |

## 5. Anti-Patterns

- ❌ Dark patterns — tricking users
- ❌ Overwhelming choice — decision paralysis
- ❌ Empty rewards — meaningless badges
- ❌ Ignoring trust — opaque data practices
- ❌ Over-reliance on extrinsic rewards

## 6. Design Checklist

- [ ] Does this reduce cognitive load?
- [ ] Are defaults set to the user's benefit?
- [ ] Does the user see clear progress?
- [ ] Have I offered value before asking?
- [ ] Is framing appropriate (loss-averse for key actions)?
- [ ] Is choice limited and well-organized?
- [ ] Does this build or damage trust?
